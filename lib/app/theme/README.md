# Theme / Diseño

Esta carpeta contiene la configuración del tema visual de la aplicación.

## Estructura Sugerida

```
theme/
├── app_theme.dart          # ThemeData principal con light/dark
├── color_schemes.dart      # Definición de esquemas de color
├── theme_constants.dart    # Constantes de diseño (colores, fuentes, tamaños, etc.)
├── theme_extensions.dart   # Extensiones de ThemeData para acceso fácil a colores, etc.
```
