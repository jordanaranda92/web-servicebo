## 5) Desviaciones respecto al análisis técnico

- **Logo:** El análisis técnico proponía `Image.asset()` con `errorBuilder`. Se
  implementó un `Icon(Icons.business_rounded)` como fallback directo, dado que
  no existe asset de logo. Cuando se proporcione el asset, se puede reemplazar
  el `Icon` por `Image.asset()` con `errorBuilder`.
- **Header logo compacto:** En estado colapsado se reduce el tamaño del icono
  (de `xl` a `lg`) en vez de mostrar un asset diferente. Es el comportamiento
  más adecuado hasta que se disponga de assets reales.
- Ambas desviaciones son menores y no cambian el alcance ni el diseño técnico.

## 6) Riesgos, incidencias y pendientes

- **Pendiente PA-01:** El asset del logo de la empresa aún no está disponible.
  Se usa un icono placeholder (`Icons.business_rounded`). Cuando se proporcione
  el logo, actualizar `_Header` en `side_menu.dart`.
- **Tooltip i18n:** Los tooltips del botón de toggle ("Colapsar menú" /
  "Expandir menú") están hardcodeados en español. Se recomienda añadir claves
  i18n para estos textos en una iteración futura.
- **Widget tests de SideMenu y SideMenuShell:** El análisis técnico sugería
  tests de widget para estos componentes. Se priorizaron los tests unitarios del
  cubit; los widget tests pueden añadirse en una iteración posterior.
